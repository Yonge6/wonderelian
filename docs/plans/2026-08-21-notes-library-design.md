# 片刻随记文章库设计

“片刻随记”将从单篇展示区升级为可持续扩展的文章入口，同时保留 WonderElian 当前克制、安静的视觉语言。

当前的《40岁，我不再急着证明自己》作为置顶主稿，使用独立的全宽大卡展示。卡片保留现有封面、标题、摘要、日期与阅读入口，并增加轻量的“置顶主稿 / Featured Essay”标识，让读者一眼理解它是整个创作世界的起点。模块主标题在桌面端收敛至 46px，减少对文章卡片的视觉竞争；手机端继续使用流动字号，避免不自然的换行。

后续文章进入置顶主稿下方的文章网格。桌面端为两列卡片，手机端为单列；只有存在第二篇文章时才显示“更多随记”，因此当前状态不会出现空白占位。文章数据继续由 `articles.js` 统一管理，通过 `featured` 字段决定置顶稿，其余文章按数组顺序展示。每篇文章仍使用独立站内路径和中英文内容，方便未来持续增加设计、AI、产品与生活主题的文章，而不需要再次改动首页结构。

验收重点：桌面标题约 46px；置顶稿全宽且层级清晰；新增文章自动进入网格；390px 手机宽度无横向溢出；中英文切换和文章详情页保持可用。
